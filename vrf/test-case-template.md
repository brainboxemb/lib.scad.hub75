# Physical verification test case template

Use one file per language and one question per test case.

The purpose of a test case is to make one physical question repeatable. Keep design history, CI status and unrelated measurements outside the test case.

**Needed**

- exact printed fixture revisions, where relevant;
- tools or measuring devices;
- camera/phone when photographic evidence is useful.
