# Upper-left corner verification extension

PR #19 extends the existing TL1 Stage 1 procedure without changing production
panel geometry.

The iteration will add three concrete verification outputs around the same
upper-left rear corner:

1. repeatable/square fixture placement rather than hand-held alignment;
2. a local corner-radius and reinforcement-intersection check;
3. a dimensioned 2D reference sheet, exported as DXF with a rendered preview.

Fixture markings will be designed for FDM printing on a Bambu Lab X2D with AMS:
coarse, readable raised markings on non-datum faces, with colour-separable
geometry where practical.
