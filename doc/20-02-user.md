# lib.scad.hub75 user manual

## Basic use

```scad
use <openscad/p5-64x32-panel/hub75_p5_64x32_panel.scad>

panel_obj = hub75_p5_64x32_panel_create();

hub75_p5_64x32_panel_build(panel_obj);
width_mm = hub75_p5_64x32_panel_width(panel_obj);
height_mm = hub75_p5_64x32_panel_height(panel_obj);
```

Create one semantic panel object and pass it to build/accessor functions rather
than copying dimensions into consumers.

## Orientation and dimensions

The library's native coordinate system and exact current physical/nominal
dimensions are maintained in the
[component manual](../openscad/p5-64x32-panel/manual.md).

## Source authority

Drawing dimensions, STEP-derived form and secondary photographs have different
authority. See [30-00-specification.md](30-00-specification.md) and the
component-local detailed design before interpreting a dimension.

## Physical-verification status

Functional verification does not mean the complete physical panel has been
verified. Current physical status and retained evidence are described in
[50-00-verification.md](50-00-verification.md) and the workbench material under
[../vrf/](../vrf/README.md).
